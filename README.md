# Shine

A small independent Android game-platform prototype inspired by blocky game hubs.

Included:
- Shine Home
- Games page
- One game: Block World
- Game ID 10000001
- Default avatar without clothing/accessories
- Avatar page
- Settings page
- GitHub Actions APK build

Upload the project contents to a GitHub repository, then use Actions -> Build Shine APK -> Run workflow. The resulting APK is available under Artifacts.

This is an original prototype and does not copy Roblox branding or proprietary assets.
